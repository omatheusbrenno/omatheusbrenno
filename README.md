### 🧭 Como eu trabalho

- **Requisito antes de código:** critérios de aceite em Gherkin (ATDD) antes da implementação.
- **Segurança desde o PR:** autenticação, autorização e OWASP Top 10 fazem parte da revisão, não de uma fase depois.
- **IA com revisão:** uso agentes de IA para acelerar a entrega, e todo código passa por pull request revisado.
